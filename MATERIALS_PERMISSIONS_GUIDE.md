# Руководство по правам доступа к материалам

## Обзор

Система теперь поддерживает контроль прав доступа к материалам уроков. Учителя могут редактировать только те материалы, которые они сами создали, а материалы, созданные администраторами, защищены от изменения.

## Как это работает

### 1. Поле `createdBy`
- Каждый материал теперь имеет поле `createdBy`, которое содержит ID пользователя, создавшего материал
- Если поле отсутствует, материал считается "старым" и может редактироваться любым учителем

### 2. Логика прав доступа
```typescript
const canEditMaterial = (material: any) => {
  // Если у материала нет createdBy, значит это старый материал (можно редактировать)
  // Если createdBy совпадает с текущим пользователем, можно редактировать
  // Если createdBy не совпадает, значит это материал админа (нельзя редактировать)
  return !material.createdBy || material.createdBy === user?._id;
};
```

### 3. Визуальные индикаторы
- **Зеленый фон**: Материалы, которые можно редактировать
- **Желтый фон**: Материалы, созданные администратором (нельзя редактировать)
- **Бейдж "Создан администратором"**: Показывает, что материал защищен
- **Отключенные поля**: Поля ввода заблокированы для защищенных материалов

## API изменения

### Создание урока (`POST /api/lessons`)
```typescript
// Автоматически добавляет createdBy к материалам
const lessonData = {
  ...req.body,
  materials: req.body.materials.map(material => ({
    ...material,
    createdBy: userId
  }))
};
```

### Обновление урока (`PUT /api/lessons/[id]`)
```typescript
// Добавляет createdBy только к новым материалам
updatedBody.materials = req.body.materials.map(material => {
  if (!material.createdBy) {
    return { ...material, createdBy: userId };
  }
  return material;
});
```

## Миграция данных

Существующие материалы были автоматически помечены как созданные администратором:
- **Endpoint**: `POST /api/debug/migrate-materials`
- **Результат**: Все существующие материалы получили `createdBy: 'admin'`

## Тестирование

### Тестовая страница
Перейдите на `/test-materials-permissions` для просмотра:
- Информации о текущем пользователе
- Списка всех уроков и их материалов
- Визуальных индикаторов прав доступа
- Статуса каждого материала

### Проверка в интерфейсе учителя
1. Откройте панель учителя
2. Выберите ученика
3. Перейдите в таб "Уроки ученика"
4. Нажмите "Редактировать" на любом уроке
5. Попробуйте отредактировать разные материалы

## Поведение в интерфейсе

### Материалы учителя (можно редактировать)
- ✅ Все поля доступны для редактирования
- ✅ Можно удалить материал
- ✅ Зеленый фон

### Материалы администратора (нельзя редактировать)
- ❌ Все поля заблокированы
- ❌ Кнопка "Удалить" скрыта
- ❌ Попытка редактирования показывает предупреждение
- ✅ Желтый фон с бейджем "Создан администратором"

## Безопасность

- Проверка прав происходит как на фронтенде, так и на бэкенде
- API автоматически добавляет `createdBy` к новым материалам
- Существующие материалы защищены от случайного изменения
- Пользователь получает понятные сообщения об ошибках
