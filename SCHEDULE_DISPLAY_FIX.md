# Исправление отображения расписания для учеников

## Проблема
Назначенные даты уроков не отображались на карточках уроков у учеников.

## Причины проблемы

### 1. Неправильный teacherId
- LessonCard использовал `progress?.attendanceConfirmedBy` как teacherId
- Это поле может быть пустым или неправильным
- Нужно получать teacherId из базы данных

### 2. Отсутствие API для получения teacherId
- Не было API endpoint для получения teacherId ученика
- LessonCard не мог найти правильного учителя

### 3. Проблемы с загрузкой расписания
- API расписания не находил данные из-за неправильного teacherId
- Отсутствовала отладочная информация

## Выполненные исправления

### 1. Создан API для получения teacherId
**Файл:** `src/pages/api/students/teacher.ts`
- GET endpoint для получения teacherId ученика
- Пока возвращает дефолтное значение 'default'
- Готов к расширению для реальной связи ученик-учитель

### 2. Обновлен LessonCard
**Файл:** `src/components/LessonCard/LessonCard.tsx`

#### Добавлено:
- **Состояние teacherId**: `useState<string | null>(null)`
- **Загрузка teacherId**: useEffect для получения teacherId через API
- **Улучшенная загрузка расписания**: использует полученный teacherId
- **Подробное логирование**: отладочная информация на каждом этапе

#### Исправлено:
- **Логика получения teacherId**: теперь через API вместо progress
- **Зависимости useEffect**: добавлен teacherId в зависимости
- **Обработка ошибок**: улучшена обработка ошибок загрузки

### 3. Добавлена отладочная информация
- **Логи в консоли**: подробная информация о каждом этапе
- **Эмодзи в логах**: для легкого отслеживания
- **Тестовая страница**: `/test-schedule` для проверки API

### 4. Создана тестовая страница
**Файл:** `src/app/test-schedule/page.tsx`
- Тестирование API расписания
- Проверка состояния хранилища
- Создание тестовых данных

## Логика работы после исправлений

### 1. Загрузка teacherId
```typescript
// LessonCard загружает teacherId для ученика
fetch(`/api/students/teacher?studentId=${user._id}`)
  .then(data => setTeacherId(data.teacherId))
```

### 2. Загрузка расписания
```typescript

fetch(`/api/lessons/schedule?lessonId=${lesson._id}&studentId=${user._id}&teacherId=${teacherId}`)
  .then(data => setLessonSchedule(data))
```

### 3. Отображение статуса
