# Руководство по тестированию системы автоматического назначения дат

## 🎯 Цель тестирования

Проверить полный цикл работы системы:
1. Создание расписания учителя
2. Автоматическое назначение дат уроков
3. Отображение дат на дашборде ученика

## 🚀 Быстрое тестирование

### Вариант 1: Автоматическое тестирование (рекомендуется)

1. **Откройте страницу тестирования:**
   ```
   http://localhost:3000/test-full-cycle
   ```

2. **Нажмите "🚀 Запустить полный цикл"**
   - Система автоматически создаст расписание
   - Назначит даты для 4 уроков
   - Покажет подробный результат

3. **Проверьте результат:**
   - Должно быть сообщение "✅ Тестирование завершено!"
   - В результатах должны быть назначенные даты

### Вариант 2: Ручное тестирование

1. **Создайте расписание учителя:**
   - Откройте панель учителя
   - Выберите ученика
   - Перейдите в раздел "Расписание"
   - Настройте дни и время (например: вторник 22:10, четверг 19:00)
   - Сохраните расписание

2. **Автоматическое назначение дат:**
   - Перейдите в раздел "Уроки"
   - Нажмите "📅 Автоматически назначить даты"
   - Должно появиться сообщение об успешном назначении

3. **Проверьте результат:**
   - Откройте дашборд ученика
   - На карточках уроков должны отображаться даты занятий

## 🔍 Диагностика проблем

### Если автоматическое назначение не работает:

1. **Проверьте консоль браузера:**
   - Откройте Developer Tools (F12)
   - Перейдите на вкладку Console
   - Найдите логи с эмодзи 🔍📡✅❌📅

2. **Используйте отладочные страницы:**
   - `/debug-schedule` - полная диагностика системы
   - `/test-schedule` - тестирование API
   - `/test-full-cycle` - полный цикл тестирования

3. **Проверьте состояние хранилища:**
   - Откройте `/debug-schedule`
   - Нажмите "Refresh Status"
   - Проверьте количество сохраненных расписаний

### Типичные проблемы и решения:

#### Проблема: "Teacher schedule not found or not enabled"
**Решение:**
1. Убедитесь, что расписание создано в разделе "Расписание"
2. Проверьте, что расписание включено (enabled: true)
3. Проверьте, что выбраны активные дни недели

#### Проблема: "No enabled days in teacher schedule"
**Решение:**
1. Откройте раздел "Расписание"
2. Включите хотя бы один день недели
3. Сохраните расписание

#### Проблема: Даты не отображаются на дашборде ученика
**Решение:**
1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что teacherId правильно передается
3. Проверьте, что расписание уроков сохранено

## 📊 Ожидаемые результаты

### После успешного автоматического назначения:

1. **В TeacherLessonsTab:**
   - Кнопка "📅 Автоматически назначить даты" должна показать успех
   - Должно появиться сообщение: "✅ Автоматически назначено X уроков!"

2. **В хранилище данных:**
   - Должно быть 1 расписание учителя
   - Должно быть 4 расписания уроков (по количеству уроков)

3. **На дашборде ученика:**
   - Вместо "Не начат" должны отображаться даты
   - Формат: "ДД.ММ.ГГГГ в ЧЧ:ММ"
   - Для прошлых дат: "Пропущен (ДД.ММ.ГГГГ в ЧЧ:ММ)"
   - Для сегодня: "Сегодня в ЧЧ:ММ"

### Примеры отображения дат:

```
Урок 1: Вторник 22.10.2024 в 22:10
Урок 2: Четверг 24.10.2024 в 19:00
Урок 3: Вторник 29.10.2024 в 22:10
Урок 4: Четверг 31.10.2024 в 19:00
```

## 🛠️ Инструменты для диагностики

### Логи в консоли:
- 🔍 **Поиск данных**: загрузка teacherId и расписания
- 📡 **API ответы**: статус ответов от сервера
- ✅ **Успешные операции**: данные загружены
- ❌ **Ошибки**: проблемы с загрузкой
- 📅 **Обработка дат**: логика отображения дат

### API endpoints для тестирования:
- `GET /api/debug/schedule-storage` - состояние хранилища
- `POST /api/debug/schedule-storage` - очистка хранилища
- `GET /api/schedule/teacher` - получение расписания учителя
- `POST /api/schedule/teacher` - создание расписания учителя
- `POST /api/lessons/auto-schedule` - автоматическое назначение
- `GET /api/lessons/schedule` - получение расписания урока
