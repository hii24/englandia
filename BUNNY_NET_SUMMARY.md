## Как использовать

1. **Админ загружает видео в dash.bunny.net**
2. **Копирует код видео** (например: `d2a2d931-f32e-48a4-8d76-20b1f2f714cc`)
3. **Добавляет код в урок** через админ-панель
4. **Видео автоматически отображается** в карточке урока

## Технические детали

- **URL видео**: `https://iframe.mediadelivery.net/embed/459943/{videoId}`
- **ID библиотеки по умолчанию**: `459943`
- **Безопасность**: HTTPS, iframe с настройками безопасности
- **Адаптивность**: responsive дизайн (16:9)

# Интеграция Bunny.net и игр в уроки

## Обзор

Реализована интеграция с dash.bunny.net для загрузки и отображения видео уроков, а также добавлена поддержка интерактивных игр через iframe.

## Видео через Bunny.net

### Модель данных
- Добавлено поле `bunnyVideoId` в модель урока
- Хранит код видео из dash.bunny.net

### Компонент BunnyVideoPlayer
- React компонент для встраивания видео через iframe
- Поддержка адаптивного дизайна
- Безопасные атрибуты iframe

### Административная панель
- Поле для ввода кода видео в CreateLessonTab и EditLessonsTab
- Отладочные логи для отслеживания сохранения

### Отображение
- Видео отображается в конце карточки урока
- Отдельная секция с заголовком "Видео урока"
- Стилизация с границей и отступами

## Игры для уроков

### Модель данных
- Добавлено поле `games` в модель урока
- Массив игр с полями: title, iframeUrl, description, forStudent

### Компонент GameGrid
- Отображение игр в сетке из двух колонок
- Адаптивный дизайн (1 колонка на мобильных)
- Карточки с заголовком, описанием и iframe
- Иконка 🎮 в заголовке секции

### Административная панель
- Новая вкладка "Игры" в CreateLessonTab и EditLessonsTab
- Добавление/редактирование/удаление игр
- Настройка видимости для учеников

### Отображение
- Игры отображаются после видео в карточке урока
- Отдельная секция с границей сверху
- Высота iframe: 300px на десктопе, 250px на мобильных

## API обновления

### Создание урока
```typescript
POST /api/lessons
{
  "title": "Название урока",
  "bunnyVideoId": "d2a2d931-f32e-48a4-8d76-20b1f2f714cc",
  "games": [
    {
      "title": "Название игры",
      "iframeUrl": "https://example.com/game",
      "description": "Описание игры",
      "forStudent": true
    }
  ]
}
```

### Обновление урока
- Добавлено поле `games` в разрешенные поля для обновления
- Поддержка обновления видео и игр

## Тестирование

### Тестовые страницы

- `/test-bunny-save` - тест сохранения видео кода

### Отладочные логи

## Использование

### Добавление видео
1. Загрузите видео в dash.bunny.net
2. Скопируйте код видео (например: d2a2d931-f32e-48a4-8d76-20b1f2f714cc)
3. Вставьте код в поле "Код видео Bunny.net" в админке
4. Сохраните урок

### Добавление игр
1. В админке перейдите на вкладку "Игры"
2. Нажмите "+ Добавить игру"
3. Заполните поля:
   - Название игры
   - URL для iframe
   - Описание (опционально)
   - Настройте видимость для учеников
4. Сохраните урок

## Безопасность

### iframe атрибуты
- allowFullScreen для полноэкранного режима
- Разрешенные атрибуты: accelerometer, autoplay, clipboard-write, encrypted-media, gyroscope, picture-in-picture

### Валидация данных
- Проверка типов данных в API
- Санитизация URL для iframe

## Миграция

Для существующих уроков:
- Поле `bunnyVideoId` будет undefined
- Поле `games` будет пустым массивом
- Никаких дополнительных действий не требуется
