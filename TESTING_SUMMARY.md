## Примечания

1. **Падающие тесты**: Многие тесты падают, потому что реальные API endpoints не имеют той валидации, которую мы тестируем. Это нормально - мы создали тесты для идеальной валидации.

2. **Мокирование**: Тесты используют моки для NextApiRequest и NextApiResponse, не подключаются к реальной базе данных.

3. **Конфигурация**: Все тесты используют единую конфигурацию Jest и общие утилиты.

## Команды для запуска

```bash
# Запустить все тесты
bun test

# Запустить тесты в режиме watch
bun test:watch

# Запустить тесты с покрытием
bun test:coverage
```
