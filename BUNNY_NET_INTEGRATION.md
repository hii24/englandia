# Интеграция с Bunny.net

## Описание

Интеграция с dash.bunny.net для загрузки и отображения видео в уроках.

## Как использовать

### 1. Получение кода видео из dash.bunny.net

1. Зайдите в [dash.bunny.net](https://dash.bunny.net)
2. Загрузите видео в вашу библиотеку
3. Скопируйте код видео (GUID) - например: `d2a2d931-f32e-48a4-8d76-20b1f2f714cc`

### 2. Добавление видео к уроку

#### Через админ-панель (CreateLessonTab)
1. Откройте админ-панель
2. Перейдите на вкладку "Создать урок"
3. В поле "Код видео Bunny.net" вставьте код видео
4. Сохраните урок

#### Через настройки (SettingsModal)
1. Откройте настройки
2. Перейдите на вкладку "Создать урок"
3. В поле "Код видео Bunny.net" вставьте код видео
4. Нажмите "Создать урок"

#### Через редактирование урока (EditLessonsTab)
1. Откройте админ-панель
2. Перейдите на вкладку "Редактировать уроки"
3. Выберите урок для редактирования
4. В поле "Код видео Bunny.net" вставьте код видео
5. Сохраните изменения

### 3. Отображение видео

Видео отображается в **отдельной секции в конце карточки урока** с заголовком "Видео урока" 🎥 для всех пользователей, если указан код видео.

**Структура отображения:**
- Ссылка на занятие
- Учебные материалы урока
- Домашнее задание
- Дополнительные материалы
- **Видео урока** (отдельная секция с иконкой 🎥 в конце)

Видео отображается развернутым в конце карточки с визуальным разделителем (границей сверху).

## Технические детали

### Модель данных

В модель `Lesson` добавлено поле:
```typescript
bunnyVideoId: String // Код видео из Bunny.net
```

### Компоненты

- `BunnyVideoPlayer` - переиспользуемый компонент для отображения видео
- Обновлен `LessonCard` для отображения видео в отдельной секции
- Обновлены формы создания и редактирования уроков

### API

Видео отображается через iframe с URL:
```
https://iframe.mediadelivery.net/embed/{libraryId}/{videoId}?autoplay=false&loop=false&muted=false&preload=true&responsive=true
```

Где:
- `libraryId` = '459943' (ID библиотеки по умолчанию)
- `videoId` = код видео из dash.bunny.net

## Пример использования

```typescript
// В компоненте
<BunnyVideoPlayer 
  videoId="d2a2d931-f32e-48a4-8d76-20b1f2f714cc"
  autoplay={false}
  loop={false}
  muted={false}
/>
```

## Настройки

При необходимости можно изменить ID библиотеки по умолчанию в компоненте `BunnyVideoPlayer` или передать его как пропс.

## Безопасность

- Видео загружается только по HTTPS
- Используется iframe с настройками безопасности
- Код видео валидируется на стороне клиента
