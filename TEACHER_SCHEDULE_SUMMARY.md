# Отчет о реализации расписания для учителя

## Описание функциональности

Реализована система управления расписанием для учителей, позволяющая назначать **разное время проведения занятий для каждого дня недели** с учетом тарифов учеников.

### 3. Создание компонента TeacherScheduleTab

**Файл:** `src/components/admin/TeacherScheduleTab.tsx`

**Функциональность:**
- **Выбор ученика**: Компонент работает только при выбранном ученике
- **Настройка расписания**: Включение/выключение расписания
- **Индивидуальное время для каждого дня**: Возможность установить разное время для понедельника, вторника и т.д.
- **Выбор дней недели**: Чекбоксы для каждого дня недели
- **Установка времени**: Поле для выбора времени занятий для каждого дня отдельно
- **Часовой пояс**: Выбор часового пояса
- **Предварительный просмотр**: Отображение настроенного расписания по дням
- **Учет тарифов**: Отображение тарифа ученика

**Интерфейс:**
```typescript
interface DaySchedule {
  day: string;
  time: string;
  enabled: boolean;
}

interface ScheduleSettings {
  enabled: boolean;
  daysSchedule: DaySchedule[];
  timezone: string;
}
```

**Особенности:**
- **Гибкое расписание**: Каждый день может иметь свое время (например, понедельник в 19:00, пятница в 10:00)
- Красивый современный дизайн с CSS-in-JS
- Адаптивная верстка для мобильных устройств
- Валидация данных (обязательные поля при включенном расписании)
- Информационная панель с подсказками
- Состояние загрузки при сохранении
- Детальный предварительный просмотр расписания

### 4. Создание API endpoint для расписания

**Файл:** `src/pages/api/schedule/teacher.ts`

**Функциональность:**
- **GET**: Получение расписания для конкретного ученика и учителя
- **POST**: Сохранение/обновление расписания с поддержкой разного времени для разных дней
- **Валидация**: Проверка существования учителя и ученика
- **Безопасность**: Проверка роли учителя
- **Гибкость**: Поддержка индивидуального времени для каждого дня

**Структура данных:**
```typescript
interface DaySchedule {
  day: string;
  time: string;
  enabled: boolean;
}

interface TeacherSchedule {
  teacherId: string;
  studentId: string;
  enabled: boolean;
  daysSchedule: DaySchedule[];
  timezone: string;
  createdAt: Date;
  updatedAt: Date;
}
```

**Особенности:**
- Временное хранилище в памяти (готово к переносу в базу данных)
- Подробное логирование операций
- Обработка ошибок с информативными сообщениями
- Валидация входных данных
- Поддержка параметров из query и body
- Дефолтное расписание для всех дней недели

## Логика работы с тарифами

### Определение тарифа ученика:
- **Гость (guest)**: "Нет подписки" - доступ только к первому уроку
- **Студент (student)**: По умолчанию "4 урока/мес" (готово к расширению)

### Влияние тарифа на расписание:
- **4 урока/мес**: Рекомендуется 1-2 дня в неделю
- **8 уроков/мес**: Рекомендуется 2-3 дня в неделю
- Система автоматически учитывает тариф при отображении информации

## Пользовательский интерфейс

### Основные элементы:
1. **Заголовок**: Название ученика и его тариф
2. **Переключатель**: Включение/выключение расписания
3. **Дни недели с временем**: Отдельные карточки для каждого дня с чекбоксом и полем времени
4. **Часовой пояс**: Выпадающий список с популярными часовыми поясами
5. **Предварительный просмотр**: Детальное отображение настроенного расписания по дням
6. **Информационная панель**: Подсказки по использованию

### Дизайн:
- Современный минималистичный стиль
- Фиолетовая цветовая схема (#7c3aed)
- Плавные анимации и переходы
- Адаптивная верстка
- Hover-эффекты для интерактивных элементов
- Карточки для каждого дня недели

## Безопасность и валидация

### Проверки безопасности:
- Валидация существования учителя и ученика
- Проверка роли учителя (только 'teacher')
- Проверка принадлежности ученика к учителю

### Валидация данных:
- Обязательные дни недели при включенном расписании
- Обязательное время для выбранных дней
- Корректность формата времени
- Валидность часового пояса
- Проверка, что хотя бы один день выбран при включенном расписании

## Исправленные проблемы

### API ошибка "studentId and teacherId are required":
- **Проблема**: API ожидал параметры в query, но компонент отправлял их в body
- **Решение**: Обновлен API для поддержки параметров из query и body
- **Результат**: API работает корректно с обоими способами передачи параметров

Система готова к использованию и позволяет учителям эффективно управлять расписанием занятий для каждого ученика с учетом их тарифов и предпочтений. **Новая функциональность позволяет устанавливать разное время для каждого дня недели**, что делает расписание максимально гибким и удобным.
