# Автоматическое расписание уроков

## Обзор

Система автоматического расписания позволяет учителям автоматически назначать даты для всех доступных уроков на основе настроенного расписания.

## Основные компоненты

### 1. API Endpoint: `/api/lessons/auto-schedule`

**Метод:** POST  
**Параметры:**
- `studentId` (query) - ID ученика
- `teacherId` (query) - ID учителя
- `startDate` (body) - дата начала расписания (опционально)
- `lessonsCount` (body) - количество уроков для назначения (опционально, по умолчанию все доступные)

**Логика работы:**
1. Получает расписание учителя из MongoDB
2. Если расписание не найдено, создает дефолтное
3. Получает все активные уроки из базы данных
4. Генерирует даты для всех доступных уроков (или указанного количества)
5. Сохраняет расписание каждого урока в MongoDB

**Ответ:**
```json
{
  "success": true,
  "scheduledLessons": [
    {
      "lessonId": "lesson_id",
      "scheduledDate": "2024-01-15T18:00:00.000Z",
      "time": "18:00",
      "timezone": "Europe/Moscow"
    }
  ],
  "totalLessons": 10,
  "scheduledCount": 10
}
```

### 2. Компонент: TeacherScheduleTab

**Функции:**
- Настройка расписания учителя (дни недели, время, часовой пояс)
- Автоматическое назначение уроков
- Предварительный просмотр расписания

**Автоматическое назначение:**
```typescript
const handleAutoScheduleLessons = async () => {
  const response = await fetch(`/api/lessons/auto-schedule?studentId=${studentId}&teacherId=${teacherId}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      startDate: new Date().toISOString().split('T')[0]
      // Убираем lessonsCount, чтобы генерировать на все доступные уроки
    })
  });
  
  const data = await response.json();
  alert(`Автоматически назначено ${data.scheduledCount} из ${data.totalLessons} доступных уроков!`);
};
```

## Логика автоматического назначения

### Алгоритм распределения уроков:

1. **Получение расписания учителя:**
   - Дни недели с временем
   - Часовой пояс
   - Статус активности

2. **Определение активных дней:**
   ```typescript
   const enabledDays = teacherSchedule.daysSchedule.filter(day => day.enabled);
   ```

3. **Генерация дат для уроков:**
   ```typescript
   // Используем lessonsCount если указан, иначе все доступные уроки
   const maxLessons = lessonsCount ? Math.min(lessonsCount, lessons.length) : lessons.length;
   
   while (lessonIndex < maxLessons) {
     const daySchedule = enabledDays[dayIndex % enabledDays.length];
     const lessonDate = getNextLessonDate(currentDate, daySchedule.day);
     // Установка времени занятия
     lessonDate.setHours(parseInt(hours), parseInt(minutes), 0, 0);
   }
   ```

4. **Циклическое распределение:**
   - Если выбрано 2 дня (понедельник, среда)
   - Урок 1 → понедельник
   - Урок 2 → среда
   - Урок 3 → понедельник (следующая неделя)
   - Урок 4 → среда (следующая неделя)
   - И так далее для всех доступных уроков

### Примеры распределения:

#### Сценарий 1: 2 дня в неделю, 10 уроков
```
Расписание: Понедельник 18:00, Среда 19:00
Уроки: 10 уроков

Результат:
- Урок 1: Понедельник 18:00
- Урок 2: Среда 19:00
- Урок 3: Понедельник 18:00 (следующая неделя)
- Урок 4: Среда 19:00 (следующая неделя)
- Урок 5: Понедельник 18:00 (3-я неделя)
- Урок 6: Среда 19:00 (3-я неделя)
- Урок 7: Понедельник 18:00 (4-я неделя)
- Урок 8: Среда 19:00 (4-я неделя)
- Урок 9: Понедельник 18:00 (5-я неделя)
- Урок 10: Среда 19:00 (5-я неделя)
```

#### Сценарий 2: 3 дня в неделю, 15 уроков
```
Расписание: Вторник 18:00, Четверг 19:00, Суббота 10:00

Результат:
- Уроки 1-3: Вторник, Четверг, Суббота (1-я неделя)

```

## Обработка ошибок

### Возможные ошибки:
1. **Расписание учителя не включено**
2. **Нет активных дней в расписании**
3. **Нет активных уроков в системе**
4. **Ошибки валидации ObjectId**

### Логирование:
- Все операции логируются в консоль
- Ошибки сохраняются в тестовых результатах
- Статус хранилища доступен через debug API
