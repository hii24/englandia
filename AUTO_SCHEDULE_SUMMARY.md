# Отчет о реализации системы автоматического назначения дат уроков

## Описание функциональности

Реализована система автоматического назначения дат для уроков на основе расписания учителя с возможностью кастомизации отдельных уроков. Система синхронизирует общее расписание учителя с конкретными датами уроков.

## Выполненные изменения

### 1. Исправление ошибки API

**Проблема:** `"lessonId, studentId and teacherId are required"`

**Решение:** Обновлен способ передачи параметров в API
- Параметры теперь передаются в URL query string
- Body содержит только данные расписания

**Файл:** `src/components/admin/TeacherLessonsTab.tsx`

### 2. Создание API endpoint для автоматического назначения

**Файл:** `src/pages/api/lessons/auto-schedule.ts`

**Функциональность:**
- **POST**: Автоматическое назначение дат уроков на основе расписания учителя
- **Валидация**: Проверка существования учителя, ученика и расписания
- **Логика назначения**: Умное распределение уроков по дням недели

**Алгоритм работы:**
1. Получение расписания учителя для ученика
2. Получение списка активных уроков
3. Определение активных дней недели
4. Генерация дат для уроков с учетом расписания
5. Сохранение назначенных дат

**Структура данных:**
```typescript
interface AutoScheduleRequest {
  startDate: string;      // Дата начала (опционально)
  lessonsCount: number;   // Количество уроков (по умолчанию 4)
}

interface AutoScheduleResponse {
  success: boolean;
  scheduledLessons: Array<{
    lessonId: string;
    scheduledDate: string;
    time: string;
    timezone: string;
  }>;
}
```

## Логика автоматического назначения

### Алгоритм распределения уроков:

1. **Получение расписания учителя:**
   - Дни недели с временем
   - Часовой пояс
   - Статус активности

2. **Определение активных дней:**
   ```typescript
   const enabledDays = teacherSchedule.daysSchedule.filter(day => day.enabled);
   ```

3. **Генерация дат для уроков:**
   ```typescript
   while (lessonIndex < lessonsCount) {
     const daySchedule = enabledDays[dayIndex % enabledDays.length];
     const lessonDate = getNextLessonDate(currentDate, daySchedule.day);
     // Установка времени занятия
     lessonDate.setHours(parseInt(hours), parseInt(minutes), 0, 0);
   }
   ```

4. **Циклическое распределение:**
   - Если выбрано 2 дня (понедельник, среда)
   - Урок 1 → понедельник
   - Урок 2 → среда
   - Урок 3 → понедельник (следующая неделя)
   - Урок 4 → среда (следующая неделя)

### Примеры распределения:

#### Сценарий 1: 2 дня в неделю
```
Расписание: Понедельник 18:00, Среда 19:00
Уроки: 4 урока

Результат:
- Урок 1: Понедельник 18:00
- Урок 2: Среда 19:00
- Урок 3: Понедельник 18:00 (следующая неделя)
- Урок 4: Среда 19:00 (следующая неделя)
```

#### Сценарий 2: 3 дня в неделю
```
Расписание: Вторник 18:00, Четверг 19:00, Суббота 10:00
Уроки: 6 уроков

Результат:
- Урок 1: Вторник 18:00
- Урок 2: Четверг 19:00
- Урок 3: Суббота 10:00
- Урок 4: Вторник 18:00 (следующая неделя)
- Урок 5: Четверг 19:00 (следующая неделя)
- Урок 6: Суббота 10:00 (следующая неделя)
```

## Использование

### Автоматическое назначение:
1. **Через TeacherLessonsTab**: Нажмите "📅 Автоматически назначить даты"
2. **Через TeacherScheduleTab**: Сохраните расписание и согласитесь на автоматическое назначение
3. **Результат**: Все уроки получают даты на основе расписания учителя

### Кастомизация отдельных уроков:
1. В TeacherLessonsTab найдите нужный урок
2. Используйте кнопку "Назначить" для быстрого назначения
3. Используйте кнопку "Отменить" для отмены назначения
4. Изменения применяются только к выбранному уроку

### Логика работы:
- **Общее расписание**: Учитель настраивает дни и время занятий
- **Автоматическое назначение**: Система распределяет уроки по дням
- **Кастомизация**: Учитель может изменить отдельные уроки
- **Синхронизация**: Ученик видит актуальные даты занятий

Система обеспечивает гибкость и удобство планирования занятий, автоматизируя рутинные задачи и позволяя кастомизировать отдельные уроки при необходимости.
