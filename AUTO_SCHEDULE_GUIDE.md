# Руководство по использованию системы автоматического назначения дат

## 🚀 Быстрый старт

### Вариант 1: Автоматическое создание расписания (рекомендуется)

1. **Откройте панель учителя** для нужного ученика
2. **Перейдите в раздел "Уроки"**
3. **Нажмите кнопку "📅 Автоматически назначить даты"**
4. **Система автоматически:**
   - Создаст дефолтное расписание (понедельник и среда в 18:00)
   - Назначит даты для 4 уроков
   - Покажет результат

### Вариант 2: Ручное создание расписания

1. **Откройте панель учителя** для нужного ученика
2. **Перейдите в раздел "Расписание"**
3. **Настройте дни недели и время:**
   - Выберите активные дни
   - Установите время для каждого дня
   - Выберите часовой пояс
4. **Сохраните расписание**
5. **Согласитесь на автоматическое назначение дат** (если предложено)
6. **Или перейдите в раздел "Уроки"** и нажмите "📅 Автоматически назначить даты"

## 🔧 Настройка расписания

### Дефолтное расписание (создается автоматически):
- **Понедельник**: 18:00 ✅
- **Вторник**: 18:00 ❌
- **Среда**: 18:00 ✅
- **Четверг**: 18:00 ❌
- **Пятница**: 18:00 ❌
- **Суббота**: 10:00 ❌
- **Воскресенье**: 10:00 ❌

### Логика распределения уроков:
- **4 урока** → распределяются по активным дням
- **Циклическое распределение**: если 2 активных дня, уроки чередуются
- **Время**: берется из расписания для каждого дня

### Примеры распределения:

#### 2 дня в неделю (понедельник, среда):
```
Урок 1: Понедельник 18:00
Урок 2: Среда 18:00  
Урок 3: Понедельник 18:00 (следующая неделя)
Урок 4: Среда 18:00 (следующая неделя)
```

#### 3 дня в неделю (вторник, четверг, суббота):
```
Урок 1: Вторник 18:00
Урок 2: Четверг 18:00
Урок 3: Суббота 10:00
Урок 4: Вторник 18:00 (следующая неделя)
```

## 🎯 Кастомизация отдельных уроков

### После автоматического назначения:
1. **В разделе "Уроки"** найдите нужный урок
2. **Используйте кнопки:**
   - **"Назначить"** → быстро назначить дату
   - **"Отменить"** → убрать назначенную дату
3. **Изменения применяются только к выбранному уроку**

## 🔍 Диагностика проблем

### Ошибка: "Teacher schedule not found or not enabled"

**Причина:** Расписание учителя не создано или отключено

**Решение:**
1. Перейдите в раздел "Расписание"
2. Создайте расписание для ученика
3. Убедитесь, что расписание включено
4. Попробуйте автоматическое назначение снова

### Ошибка: "No enabled days in teacher schedule"

**Причина:** В расписании нет активных дней

**Решение:**
1. Откройте раздел "Расписание"
2. Включите хотя бы один день недели
3. Сохраните расписание
4. Попробуйте снова

### Ошибка: 404 в API progress/student-lesson

**Причина:** Запись прогресса не найдена

**Решение:** 
- Система автоматически создает дефолтную запись
- Ошибка исправлена в последнем обновлении
