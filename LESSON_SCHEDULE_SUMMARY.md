# Отчет о реализации системы назначения дат для уроков

## Описание функциональности

Реализована система назначения дат для отдельных уроков, позволяющая учителям назначать конкретные даты и время для каждого урока ученика, а ученикам видеть эту информацию в статусе урока вместо "Не начат".

## Выполненные изменения

### 1. Создание API endpoint для расписания уроков

**Файл:** `src/pages/api/lessons/schedule.ts`

**Функциональность:**
- **GET**: Получение расписания для конкретного урока, ученика и учителя
- **POST**: Сохранение/обновление расписания урока
- **Валидация**: Проверка существования учителя, ученика и урока
- **Безопасность**: Проверка роли учителя

**Структура данных:**
```typescript
interface LessonSchedule {

  studentId: string;
  teacherId: string;
  scheduledDate: string;
  time: string;

  updatedAt: Date;

```

**Особенности:**
- Временное хранилище в памяти (готово к переносу в базу данных)
- Подробное логирование операций
- Обработка ошибок с информативными сообщениями
- Валидация входных данных
- Поддержка параметров из query и body

### 3. Обновление LessonCard для учеников

**Файл:** `src/components/LessonCard/LessonCard.tsx`

**Новые функции:**
- **Загрузка расписания**: Получение информации о дате урока для ученика
- **Умный статус**: Отображение даты вместо "Не начат"
- **Логика дат**: Различное отображение в зависимости от даты

**Логика отображения статуса:**
```typescript
const getStatusText = () => {
  if (status === 'completed') return 'Завершён';
  
  if (user?.role === 'student' && lessonSchedule?.enabled && lessonSchedule?.scheduledDate) {
    const scheduledDate = new Date(lessonSchedule.scheduledDate);
    const now = new Date();
    
    // Если дата в прошлом
    if (scheduledDate < now) {
      return `Пропущен (${scheduledDate.toLocaleDateString('ru-RU')} в ${lessonSchedule.time})`;
    }
    
    // Если дата сегодня
    if (scheduledDate.toDateString() === now.toDateString()) {
      return `Сегодня в ${lessonSchedule.time}`;
    }
    
    // Если дата в будущем
    return `${scheduledDate.toLocaleDateString('ru-RU')} в ${lessonSchedule.time}`;
  }
  
  return 'Не начат';
};
```

## Пользовательский интерфейс

### Для учителей:

#### Карточка урока в TeacherLessonsTab:
1. **Заголовок урока**: Номер и название урока
2. **Описание урока**: Краткое описание
3. **Статус посещения**: Посетил/Не посетил с датой
4. **Расписание урока**: 
   - Если назначено: "15.12.2024 в 18:00" + кнопка "Отменить"
   - Если не назначено: "Не назначено" + кнопка "Назначить"
5. **Кнопки управления**: Изменение статуса посещения
6. **Кнопка редактирования**: Редактирование материалов урока

#### Функциональность:
- **Быстрое назначение**: Одна кнопка для назначения даты на сегодня в 18:00
- **Отмена расписания**: Возможность отменить назначенную дату
- **Автоматическое обновление**: Интерфейс обновляется после изменений

### Для учеников:

#### Карточка урока на дашборде:
1. **Заголовок урока**: Номер и название урока
2. **Описание урока**: Краткое описание
3. **Умный статус**:
   - **Завершён**: "Завершён" (зеленый)
   - **Сегодня**: "Сегодня в 18:00" (серый)
   - **Будущее**: "20.12.2024 в 18:00" (серый)
   - **Пропущен**: "Пропущен (15.12.2024 в 18:00)" (серый)
   - **Не назначено**: "Не начат" (серый)

## Примеры использования

### Сценарий 1: Учитель назначает даты уроков
1. Учитель выбирает ученика
2. Переходит на вкладку "Уроки ученика"
3. Видит список уроков с кнопками "Назначить"
4. Нажимает "Назначить" для урока 1 → автоматически назначается сегодня в 18:00
5. Ученик видит в своем дашборде: "Сегодня в 18:00"

### Сценарий 2: Учитель отменяет назначенную дату
1. Учитель видит назначенную дату: "15.12.2024 в 18:00"
2. Нажимает "Отменить"
3. Статус меняется на "Не назначено"
4. Ученик видит: "Не начат"

### Сценарий 3: Ученик видит разные статусы
- **Урок 1**: "Сегодня в 18:00" (урок назначен на сегодня)
- **Урок 2**: "20.12.2024 в 18:00" (урок назначен на будущее)
- **Урок 3**: "Пропущен (15.12.2024 в 18:00)" (урок был в прошлом)
- **Урок 4**: "Не начат" (дата не назначена)

## Безопасность и валидация

### Проверки безопасности:
- Валидация существования учителя, ученика и урока
- Проверка роли учителя (только 'teacher')
- Проверка принадлежности ученика к учителю

### Валидация данных:
- Обязательная дата при включенном расписании
- Обязательное время при включенном расписании
- Корректность формата даты и времени
- Валидность часового пояса

## Использование

### Для учителей:
1. Выберите ученика в панели учителя
2. Перейдите на вкладку "Уроки ученика"
3. Для каждого урока используйте кнопку "Назначить" для быстрого назначения даты
4. Используйте кнопку "Отменить" для отмены назначенной даты
5. Ученик автоматически увидит обновленную информацию

### Для учеников:
1. Откройте дашборд
2. Просмотрите карточки уроков
3. В статусе каждого урока увидите:
   - Дату и время назначенного занятия
   - "Сегодня" для занятий сегодня
   - "Пропущен" для прошедших занятий
   - "Не начат" для неназначенных занятий

Система готова к использованию и позволяет эффективно управлять расписанием отдельных уроков, обеспечивая синхронизацию между учителями и учениками.
