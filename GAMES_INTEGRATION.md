# Интеграция игр в уроки

## Обзор

Добавлена возможность включать интерактивные игры в уроки через iframe. Игры отображаются в отдельной секции после видео урока в виде сетки из двух колонок.

## Структура данных

### Модель игры (GameSchema)
```typescript
interface LessonGame {
  title: string;        // Название игры
  iframeUrl: string;    // URL для iframe игры
  description: string;  // Описание игры
  forStudent: boolean;  // Показывать ли ученику
}
```

### Обновленная модель урока
```typescript
const LessonSchema = new Schema({
  // ... существующие поля
  games: [GameSchema], // Массив игр для урока
});
```

## Компоненты

### GameGrid
Компонент для отображения игр в сетке из двух колонок.

**Особенности:**
- Адаптивная сетка (2 колонки на десктопе, 1 на мобильных)
- Каждая игра отображается в отдельной карточке
- Высота iframe: 300px на десктопе, 250px на мобильных
- Поддержка описания игры
- Иконка 🎮 в заголовке секции

**Использование:**
```tsx
import { GameGrid } from '@/components/ui/GameGrid';

<GameGrid games={lesson.games} />
```

## API

### Создание урока с играми
```typescript
POST /api/lessons
{
  "title": "Название урока",
  "games": [
    {
      "title": "Название игры",
      "iframeUrl": "https://example.com/game",
      "description": "Описание игры",
      "forStudent": true
    }
  ]
}
```

### Обновление урока с играми
```typescript
PUT /api/lessons/[id]
{
  "games": [
    {
      "title": "Обновленное название",
      "iframeUrl": "https://example.com/updated-game",
      "description": "Обновленное описание",
      "forStudent": true
    }
  ]
}
```

## Отображение в LessonCard

Игры отображаются в конце карточки урока после видео:
1. Видео урока (если есть)
2. Секция игр (если есть)

### Стилизация
- Отдельная секция с границей сверху
- Заголовок с иконкой 🎮
- Сетка из двух колонок
- Карточки с тенью и скругленными углами
- Адаптивный дизайн

## Примеры использования

### Добавление игры через админку
1. Откройте админ-панель
2. Перейдите к созданию/редактированию урока
3. Выберите вкладку "Игры"
4. Нажмите "+ Добавить игру"
5. Заполните поля:
   - Название игры
   - URL для iframe (например, https://www.youtube.com/embed/VIDEO_ID)
   - Описание (опционально)
   - Отметьте "Показывать ученику" если нужно
6. Сохраните урок

### Поддерживаемые iframe источники
- YouTube (embed URL)
- Игровые платформы
- Образовательные игры
- Любые другие iframe-совместимые источники

## Безопасность

- iframe загружается с атрибутами безопасности
- Поддержка allowFullScreen для полноэкранного режима
- Разрешенные атрибуты: accelerometer, autoplay, clipboard-write, encrypted-media, gyroscope, picture-in-picture

### Проверка сохранения
1. Создайте урок с играми через админку
2. Проверьте логи в консоли браузера
3. Убедитесь, что игры отображаются в карточке урока
4. Проверьте сохранение в базе данных

## Миграция

Для существующих уроков поле `games` будет пустым массивом по умолчанию. Никаких дополнительных действий не требуется.
